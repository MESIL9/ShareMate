# 쉐어메이트 – 대여 · 물물교환 앱

순수 HTML / CSS / JS로 만든 모바일 웹앱입니다. **설치·빌드 과정이 없습니다.**

## 실행 방법

### 1) 가장 간단하게
압축을 풀고 `index.html`을 더블클릭 → 브라우저(Chrome 권장)에서 바로 실행됩니다.

### 2) 로컬 서버로 실행 (권장)
```bash
cd sharemate
python3 -m http.server 8000      # 또는: npx serve
```
브라우저에서 http://localhost:8000 접속

### 3) 내 폰으로 확인하기
같은 Wi-Fi에서 위 서버를 켠 뒤, 폰 브라우저로 `http://<내 컴퓨터 IP>:8000` 접속.
(PC 브라우저에서는 F12 → 기기 툴바(Ctrl+Shift+M)로 모바일 화면 확인 가능)

### 4) 링크로 공유
`sharemate` 폴더를 GitHub Pages, Netlify Drop(https://app.netlify.com/drop), Vercel 등에 올리면 URL이 생깁니다.

## 파일 구성
| 파일 | 역할 |
|---|---|
| `index.html` | 껍데기 (폰 프레임 + 스크립트 연결) |
| `style.css` | 디자인 (색상은 맨 위 `:root` 변수) |
| `app.js` | 화면·데이터·기능 전부 (화면별 함수로 분리) |
| `backend.js` | Firebase 이메일 로그인 · 게시글 · 실시간 채팅 · 리뷰 |
| `firebase-config.js` | Firebase 키 입력 파일 (비우면 데모 모드) |
| `firestore.rules` | Firestore 보안 규칙 (콘솔에 붙여넣기) |

## 주요 기능
- **대여**: 전체 / 대여제품 / 대여요청 탭, 기간·카테고리 필터, 정렬(신상품 · 가격 낮은순 · 가격 높은순 · 리뷰 많은순)
- **대여 요청**: 요청자는 대여비·보증금을 제시할 수 없고, 빌려주는 사람이 "조건 제안"으로 대여료·보증금을 제시
- **물물교환**: 교환 제품만 표시, 정렬(신상품 · 가까운순 · 인기순), 교환 제안
- **내 근처 매칭**: 희망 키워드(+직접 추가한 키워드)를 가까운 거리에서 올린 사람을 추천. 서로 원하는 조합이면 "서로 원해요 [게시글 제목]" 표시, 반경 설정 가능
- **키워드 알림**: 교환 글의 희망 키워드는 자동 등록, 대여는 키워드를 직접 추가 → 일치하는 새 글이 올라오면 알림
- **희망 키워드의 의미**: 다른 사용자가 등록한 물품 중 내가 찾고 싶은 물품. **카테고리 + 게시글 제목**에 키워드가 들어 있을 때만 매칭돼요 (설명 본문은 제외)
- **첫 접속 안내**: 4단계 안내 + 회원 간 거래 책임 면책 고지(동의해야 시작)
- **신고 / 차단**: 게시글·채팅방 ⋯ 메뉴, MY에서 차단 관리·신고 내역
- 대여/교환 목록, 상세, 검색 등 대부분의 화면에 **홈 버튼**

## 시연 팁
- 키워드 알림: 홈 → 🔔 → "키워드 알림 설정" → 맨 아래 **"새 글 도착시키기"**를 누르면 새 글이 올라오는 상황을 재현합니다.
- 처음 상태로 되돌리기(첫 접속 안내 다시 보기): MY → 데이터 초기화

## 알아둘 점 (프로토타입 범위)
- 서버가 없어 데이터는 브라우저 `localStorage`에 저장됩니다. 회원·위치·신고 처리·알림 푸시는 **시뮬레이션**입니다.
- 거리(km)는 샘플 데이터의 값입니다. 실서비스에서는 위치 권한(Geolocation) + 서버에서 거리 계산이 필요합니다.
- 실서비스화할 때는 `app.js`의 `S`(상태), `SEED`/`INCOMING`(샘플 데이터)를 Firebase·Supabase 등 백엔드 API로 교체하세요.

## 서버(로그인·실시간 채팅) 켜기 — Firebase
1. https://console.firebase.google.com 에서 프로젝트 생성 → **웹 앱 추가** → 설정값을 `firebase-config.js`에 붙여넣기
2. **Authentication → 로그인 방법**: **이메일/비밀번호** 사용 설정 (Google 로그인은 지원하지 않아요)
3. **Authentication → 설정 → 승인된 도메인**에 배포 주소(예: `내이름.github.io`) 추가 (localhost는 기본 허용)
4. **Firestore Database** 생성 → **규칙** 탭에 `firestore.rules` 내용 붙여넣기 → 게시
5. 반드시 `http://localhost:8000` 또는 https 주소로 열기 (file:// 로는 위치·지도가 제대로 동작하지 않아요)

로그인한 사람이 올린 글은 Firestore에 저장되고, 다른 사람이 그 글에서 채팅을 누르면 1:1 실시간 채팅방이 열려요.
(Firebase를 연결한 실서비스 모드에서는 샘플 글이 보이지 않고 실제 글만 보여요. 샘플 글·자동응답 채팅은 설정을 비운 데모 모드에서만 나와요.)

## 이번에 추가된 기능
- **캘린더**: 대여 신청 시 반납일 자동 등록, 월 달력·D-day, 알림(3일 전/1일 전/당일/연체), 브라우저 알림 허용
- **리뷰**: 대여 후 리뷰 작성, 판매자 리뷰 모아보기(`#/seller/…`: 올린 물건별 리뷰 한눈에)
- **위치**: 폰 위치(Geolocation)로 거리 계산 → 가까운 순 정렬·반경 매칭 (글 등록 시 내 좌표 저장)
- **매칭**: 맞교환(내가 원하는 것 ↔ 상대가 원하는 것)이 최우선, 교환 목록 기본 정렬이 '추천순'
- **유통기한**: 카테고리를 '음식'으로 고르면 입력칸 표시
- **게시글 수정**: 내 글 상세 → 수정
- **대여 키워드**: 대여 등록에도 키워드 칸 추가 (검색·알림에 사용)

## 로그인 · 회원가입
- **이메일 가입/로그인만 지원해요** (Google 로그인 없음). 이메일 형식, 닉네임(2~12자, 한글·영문·숫자·_), 비밀번호(8자 이상 · 영문+숫자), 비밀번호 확인을 검사하고 오류는 입력창 아래에 표시해요. 로그인 상태는 새로고침·재접속 후에도 유지돼요.
- **비밀번호 찾기**: 로그인 화면에서 이메일을 적고 "비밀번호를 잊으셨나요?"를 누르면 Firebase가 재설정 메일을 보내요. (이메일 인증·학교 도메인 제한은 넣지 않았어요)
- **실서비스 모드** (firebase-config.js 입력): 샘플 글·시연 기능이 모두 사라지고 실제 사용자 글만 보여요.
- **데모 모드** (firebase-config.js 비움): 가입/로그인이 이 브라우저(localStorage)에서만 동작하고 샘플 글이 보여요. 연습용이에요.
- 앱의 개인 데이터(관심·키워드·차단·알림·캘린더·테스트 계좌)는 계정(uid)별로 따로 저장돼요.

## 캘린더 버그 수정
- 예전: 대여 **신청/조건 제안만 해도** 캘린더에 일정이 등록됐어요.
- 지금: 신청은 `MY → 대여·교환 내역`에 **승인 대기**로만 남고, 상대와 물건을 주고받은 뒤 **‘대여 시작’**을 눌러 확정해야 캘린더에 반영돼요. 취소하면 예약 표시도 풀려요. 반납 완료하면 물품 상태가 다시 열려요.
- 이전 버전에서 잘못 등록된 확정 안 된 일정은 첫 실행 때 자동 정리돼요 (신청 내역은 남아요).

## 거래 완료 글의 공개 범위
- '거래 완료 처리'를 하면 그 글은 **① 작성자 ② 거래 상대방 ③ 찜한 사용자**에게만 보여요. (직접 주소로 들어가도 막혀요)
- 서버 모드에서는 Firestore 규칙(`firestore.rules`)이 실제로 제한해요. 글에 `done`, `partnerUid`(거래 상대방), `wishers`(찜한 사람) 필드가 저장되고, 거래 완료 처리 때 채팅한 사람 중에서 거래 상대방을 고를 수 있어요.
- **규칙을 반드시 다시 붙여넣으세요** (Firebase 콘솔 → Firestore → 규칙 → `firestore.rules` 내용 게시).
- 이 수정 이전에 올라간 글은 `done` 필드가 없어요. 작성자가 앱에 한 번 접속하면 자동으로 채워져요.

## 거래 장소 지도
- **등록/수정**: `거래 장소` 칸 아래 **지도에서 위치 선택** → 장소·주소 검색, 지도 터치, 핀 드래그, `📍 내 위치`로 만날 위치를 정해요. 장소 칸이 비어 있으면 검색한 장소 이름이 자동으로 채워져요.
- **상세 화면**: `상세정보` 탭에 거래 희망 장소 지도가 보이고, 누르면(또는 `크게 보기`) 큰 지도가 열려요. `길찾기`는 카카오맵으로 연결돼요.
- 지도는 Leaflet + OpenStreetMap이라 **API 키가 필요 없어요.** 인터넷 연결이 필요하고, `http://localhost` 또는 https 주소에서 열어야 지도 타일이 잘 불러와져요.
- 저장 필드: 글에 `mlat`, `mlng`(거래 장소 좌표)가 추가돼요. (기존 `lat`/`lng`는 글쓴이 위치라 거리 계산용으로 그대로예요.) **Firestore 규칙은 바꿀 필요 없어요.**
- 이전에 올린 글, 샘플 글은 좌표가 없어서 지도 대신 안내 문구가 보여요. 글 수정에서 위치를 추가하면 돼요.

## 간편송금 (테스트 · 모의)
- 채팅방의 **💸 송금** 버튼 → 계좌 연결(테스트 계좌, 연습용 잔액 1,000,000원) → 금액 입력 → 송금 보내기. 채팅방에 영수증 카드가 남고, `MY`에서 연결 계좌·잔액(+10만원 충전)을 볼 수 있어요.
- **실제로 돈이 이동하지 않는 모의 기능이에요.** 화면과 영수증에도 "테스트 모의 송금 · 실제 이체가 아니에요"라고 표시돼요. 거래 대금은 상대와 직접 정산하세요.
- 사용자가 `[송금완료]`로 시작하는 글을 직접 보내 영수증을 위조하는 것은 막아 뒀어요.
- 진짜 송금(금융결제원 오픈뱅킹)을 쓰려면 서버(Cloud Functions 등)에서 사용자 인증·토큰·이체 API를 호출해야 해요. 이용기관 키와 토큰은 브라우저 코드에 두면 안 돼요.

## 이번 수정 사항
- **채팅 읽음 표시**: 내가 보낸 메시지를 상대가 아직 안 읽었으면 노란 `1`, 상대가 채팅방을 열면 사라져요. (서버 모드: 채팅방 문서의 `read.{uid}`에 마지막으로 본 시각 저장 / 데모 모드: 상대가 답장하면 읽음)
- **채팅 시간**: 모든 말풍선 옆에 보낸 시간(오전/오후 h:mm) 표시
- **게시글 알림**: 내가 등록한 키워드가 제목·카테고리·(대여)키워드칸에 있을 때만 알림. 설명 본문 매칭 제외, 앱 켜기 전 글·캐시에서 다시 불러온 글·내 글·차단 회원 글·같은 글 중복 알림 제외
- **신뢰점수**: 처음 5.0, 이후 받은 리뷰 별점 평균으로 변동 (상세화면·MY)
- **키워드 기본값 제거**: 기본 키워드(카메라·과일) 삭제, 기존 사용자도 첫 실행 때 자동 정리
- **신고 3회 정지**: 신고 문서 id를 `신고자uid_대상uid`로 고정 → 한 사람이 여러 번 신고해도 1건. **서로 다른 3명**에게 신고되면 정지 화면 표시. 앱에서도 같은 회원 재신고 차단
- **상품 상세 → 상세정보 탭**에 작성자 신고 수 표시
- ⚠️ `firestore.rules`에 `reports` 규칙이 추가됐어요. **콘솔에 다시 붙여넣고 게시**하세요.
